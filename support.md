# EzMemory Support

Need help with EzMemory? Please use the support channel below.

---

## 🇺🇸 English

### How to get support

If you have questions, feedback, or encounter a bug, please open an issue on GitHub:

[Open a GitHub issue](https://github.com/idonodi/EzMemory/issues)

### What to include

Please include:

- App version
- Device model
- iOS version
- Description of the issue
